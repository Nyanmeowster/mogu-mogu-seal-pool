# MOGU MOGU 我的海豹泳池

照顧一隻會隨飽足度呈現不同體態的 2D 小海豹。遊戲收斂為「陪伴、餵食、照護、小屋」四個入口，把重點放在玩家和海豹的直接互動。

遊戲資料會保存在玩家自己的瀏覽器中。每個新玩家初始擁有 1000 枚海豹幣。

小海豹沿用最終 2D 圖像版本，包含移動、進食、撫摸反應與隨飽足度變化的體型。遊戲中的互動是專業照護模擬；現實中的野生海豹受保護，不應靠近、觸摸或餵食。

餵不同食物、摸頭／臉頰／肚子／鰭，以及上岸、清潔、探索、健康檢查，都會切換各自對應的姿勢與動作，不再重複同一張反應圖。

五種體型都具備重新製作、完整且自然的張嘴與閉嘴進食圖。食物送到嘴邊後會在兩張正常影格間切換，呈現嘴部咀嚼，同時保留不同食物各自的進食節奏。

網站會在開放操作前先載入並解碼目前體型與相鄰體型，再趁瀏覽器空閒時逐組補齊其餘素材。圖片載入失敗可自動重試，既避免互動中臨時下載，也降低手機第一次開啟時的記憶體尖峰。

遊戲泳池背景沿用封面的明亮戶外照護池風格，並在開放互動前和海豹素材一起載入。

執行「上岸休息」時，海豹會從水中移到背景右側石台，在岩台上安靜休息後再回到泳池。

Doflamingo 羽毛泳圈會以接近海豹身體的比例呈現，玩家可用滑鼠或觸控拖曳泳圈；把泳圈拉到海豹身上會依目前體型切換成專屬的抱泳圈玩水圖，並增加信任度。

小海豹具有獨立個性與生活作息，會依時間、體力、飢餓、信任和泳池玩具自主游泳、上岸休息、覓食、探索或靠近照護員。連續互動太頻繁時，牠也會以轉身表達需要空間。

陪伴頁提供呼喚名字、一起玩水、安靜陪伴和打招呼四種回應，也能直接點擊或撫摸海豹不同部位。每種選擇會切換對應姿勢、訊息、音效和震動；互動太頻繁時，海豹仍會表達想保有空間。

海豹會記住玩家最常選擇的陪伴方式與最近一次互動。再次進入泳池時，牠會依離開時間、飢餓與體力主動迎接；每天另有一個只需二選一的短情境，讓陪伴產生不同的自然回應。

陪伴按鈕採用「注意玩家、靠近、互動、回到水中或休息」的連續動作。游標停留時海豹會抬頭注視，短時間快速亂點則會轉身保持距離；期待、開心、疲倦、害羞與不耐也會直接反映在動作和對話上。

不同互動的台詞會避開連續重複，靠近、玩水、上岸、休息與咀嚼也有各自的輕量情境音。姿勢之間以短交叉淡化銜接，入水與回水會帶出水紋，不再突然換圖；手機節奏與撫摸距離另行調整，並完整支援「減少動態效果」。

首次命名後會以泳池內的小提示依序引導陪伴、餵食與照護，不使用額外教學視窗。互動進行中會清楚顯示等待狀態並暫停其他操作，避免重複點擊。

全部 60 張 2D 海豹素材都另存為統一的 5:4 透明畫布版本，校正主體中心、視覺大小與底部接觸基準，切換姿勢時不再因原始留白不同而跳動。手機版也限制單指手勢、正確處理觸控取消、縮小泳圈有效碰撞區並補上安全區與 44px 觸控目標。

瀏覽器存檔具備明確版本遷移與安全備份。若主存檔損壞會自動恢復上一份有效資料，無效資料不會覆蓋備份；較新版本的存檔則以唯讀方式開啟，避免舊版程式意外降級資料。

正式版保留命名與生日／相遇日，以及必要的飽足、信任、健康與水質狀態。食物改為直接選擇，不再要求管理庫存；隨機健康事件、成就牆、天氣資訊與備份工具不再出現在遊戲介面。

五種體型各自具備游泳轉身、爬行上岸、閉眼睡覺、嗅聞探索、正面靠近與轉身保持距離六種完整動作圖。
