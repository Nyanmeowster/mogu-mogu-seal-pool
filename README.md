# MOGU MOGU 我的海豹泳池

照顧一隻會隨飽足度呈現不同體態的 2D 小海豹。玩法參考真實港海豹習性，包含多樣化海洋飲食、上岸休息、健康觀察、水質維護、信任建立與環境豐富化，也可以購買泳池裝飾，並依離線時間獲得海豹幣。

遊戲資料會保存在玩家自己的瀏覽器中。每個新玩家初始擁有 1000 枚海豹幣。

小海豹沿用最終 2D 圖像版本，包含移動、進食、撫摸反應與隨飽足度變化的體型。遊戲中的互動是專業照護模擬；現實中的野生海豹受保護，不應靠近、觸摸或餵食。

餵不同食物、摸頭／臉頰／肚子／鰭，以及上岸、清潔、探索、健康檢查，都會切換各自對應的姿勢與動作，不再重複同一張反應圖。

五種體型都具備重新製作、完整且自然的張嘴與閉嘴進食圖。食物送到嘴邊後會在兩張正常影格間切換，呈現嘴部咀嚼，同時保留不同食物各自的進食節奏。

網站會在開放操作前預先載入並解碼五種體型的海豹素材，避免餵食、體型切換或互動期間才臨時下載圖片。

遊戲泳池背景沿用封面的明亮戶外照護池風格，並在開放互動前和海豹素材一起載入。

執行「上岸休息」時，海豹會從水中移到背景右側石台，在岩台上安靜休息後再回到泳池。
